## Discussion Notes

### Key Decisions
| Decision | Reasoning |
|---|---|
| Backfill an intent rather than skip it | AI-DLC requires intent → elaboration → unit traceability; skipping creates an audit gap |
| Bundle backend JWT + frontend Supabase JS into one unit (`supabase-project-and-auth`) | They share the JWT contract; splitting risks one stack diverging from the other |
| Separate `db-migration-tooling` from auth | Migration role separation (postgres vs app role) and EF/Supabase split deserve their own elaboration |
| EF Core for schema; Supabase SQL for RLS/seed | EF Core can't express RLS cleanly; Supabase migrations don't own table DDL; documented rule + CI guardrail script |
| Snake-case via `EFCore.NamingConventions` | CLAUDE.md §3 mandates snake_case DB; package is mature and avoids per-entity fluent boilerplate |
| Env-var feature flags, not a runtime service | YAGNI for MVP; flag system is small enough to swap later |
| Backend throws on unknown flag; frontend uses typed union | Both surfaces fail loudly on typos / dead flags |
| JWT `ClockSkew` = 30 s | Framework default of 5 min is too loose; 0 too brittle; 30 s deliberate |
| `/health` `.AllowAnonymous()` from day one | Even before any other endpoint exists, document the policy explicitly so global `[Authorize]` doesn't break it later |

### Deferred / Out of Scope
| Item | Why Deferred |
|---|---|
| GitHub Actions CI pipeline | Separate intent; this scaffold is local-build-and-test only |
| Playwright / E2E | Separate unit after first real UI exists |
| Observability (Serilog sinks, OpenTelemetry) | Future intent |
| Runtime feature-flag service | Wait until env-var-only proves insufficient |
| Admin debug endpoint for flag state | Add when an incident actually needs it |
| Cross-platform shell scripts (`.sh`) | Add when a non-Windows contributor joins |
| Central package management (`Directory.Packages.props`) | Adopted **in scope** for Unit 1 — cheaper now than to retrofit |
